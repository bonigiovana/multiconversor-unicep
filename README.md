# 🧮 MultiConversor Express

Aplicativo móvel de conversão de grandezas e unidades de medida, desenvolvido como projeto acadêmico utilizando o **MIT App Inventor**.

O aplicativo foi projetado para facilitar o dia a dia ao alternar entre o Sistema Internacional de Medidas (métrico) e o Sistema Imperial, cobrindo três grandezas fundamentais: distância, temperatura e massa.

## 🧠 Conteúdos e Conceitos Aprendidos

* **Lógica de Programação e Algoritmos:**
  * Planejamento da solução por meio de **pseudocódigo** (entrada de dados, processamento e saída).
  * Tomadas de decisão e estruturas condicionais (*se / senão*) modeladas em **fluxogramas**.
* **Tipos de Dados:**
  * **Números Reais (`Float`):** Manipulação de valores decimais para garantir precisão nos cálculos físicos.
  * **Texto (`String`):** Exibição de avisos e validação para evitar campos em branco.
* **Operações Matemáticas e Fórmulas:**
  * Aplicação prática dos operadores aritméticos (+, -, *, /) e fórmulas de conversão física (como Celsius ↔ Fahrenheit).
* **Desenvolvimento Mobile & Interface (UI):**
  * Criação de interface interativa para smartphones e tratamento de eventos de toque/clique.

## 🔄 Conversões Disponíveis

| Grandeza | De / Para | Operação |
| :--- | :--- | :--- |
| 📏 **Distância** | Quilômetros (km) ↔ Milhas (mi) | Divisão ou multiplicação por `1.609344` |
| 🌡️ **Temperatura** | Celsius (°C) ↔ Fahrenheit (°F) | `(°C * 9/5) + 32` e `(°F - 32) * 5/9` |
| ⚖️ **Massa** | Quilogramas (kg) ↔ Libras (lb) | Conversão proporcional entre as unidades |
